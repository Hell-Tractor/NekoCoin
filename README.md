# NekoCoin

NekoCoin is an app for accounting developed with [Tauri 2.0](https://v2.tauri.app/)+[Vite](https://vite.dev/)+[Vue](https://vuejs.org/)+[Vuetify](https://vuetifyjs.com/)+[Rust](https://www.rust-lang.org/). NekoCoin focuses on __Convenience__, __Safety__ and __Easy-to-use__.

The app is still under early development. It will be first avaiable on Windows and Android. Linux, MacOS and IOS will be suppported later.

## Development

0. Install [Node.js](https://nodejs.org/en) and [Rust](https://www.rust-lang.org/)
1. Config [Tauri](https://v2.tauri.app/zh-cn/start/prerequisites/#%E7%A7%BB%E5%8A%A8%E7%AB%AF%E9%85%8D%E7%BD%AE) if you want to debug with Android or IOS
2. Clone the repo.
   ```sh
   git clone https://github.com/Hell-Tractor/NekoCoin.git
   cd NekoCoin
   ```
3. Install dependencies
   ```sh
   npm install
   ```
4. Run!
   ```sh
   npm run tauri dev
   ```
